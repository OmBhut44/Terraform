# 🚀 Terraform AWS Infrastructure Project

This repository contains Terraform code for provisioning AWS infrastructure using Infrastructure as Code (IaC).

It helps automate cloud resources such as EC2, IAM, and security configurations in a clean, reusable, and scalable way.

---

## 📌 Project Overview

This project demonstrates how to use Terraform to:

✔ Configure AWS Provider  
✔ Provision AWS infrastructure  
✔ Automate cloud deployments  
✔ Follow DevOps best practices  

This repository is beginner-friendly and suitable for learning real-world Terraform workflows.

---

## 🧩 Technologies Used

- Terraform
- AWS (EC2, IAM, Security Groups)
- AWS CLI

---

## 📦 Prerequisites

Make sure you have:

- AWS Account
- Terraform installed
- AWS CLI installed
- IAM user with programmatic access
